# 모아, 부산대의 기회

부산대학교 단과대학·학과·학생지원 공지에서 지금 신청할 수 있는 장학·공모전·취업·프로그램 공고를 모아, 소속(단과대학·학과·학년)에 맞춰 보여주는 **비공식** 정보 서비스입니다.

- 공고는 매일 수집·정리되어 매시간 이 사이트에 반영됩니다.
- 대상·마감은 원문을 바탕으로 정리한 값이므로 신청 전 반드시 원문을 확인해 주세요.
- 선택한 단과대학·학과·학년은 사용자의 브라우저에 저장됩니다.
- 서비스 개선을 위해 방문 횟수, 머문 시간, 본 공고, 선택한 단과대학·학과·학년을 **개인 식별 없이 통계로만** 집계합니다. 이름·연락처·IP 주소는 저장하지 않고, 브라우저의 '추적 안 함' 설정 또는 사이트 맨 아래 버튼으로 끌 수 있습니다.
- 사이트 안의 "의견 보내기"로 틀린 정보나 개선 의견을 보낼 수 있습니다.

이 저장소에는 사이트 소스(`site/`)와 학과 목록(`collector/data/`), 자동 빌드 설정(`.github/workflows/`), 그리고 배포된 정적 파일(`index.html`, 관리자 로그인 화면 `admin/`)이 들어 있습니다. 공고 데이터는 저장소에 저장되지 않고, 자동 빌드가 공개 구글 시트를 읽어 사이트 파일 안에 넣습니다(자세한 내용은 `docs/DEPLOY.md`). 관리자 화면의 데이터는 로그인한 관리자만 읽을 수 있습니다.
